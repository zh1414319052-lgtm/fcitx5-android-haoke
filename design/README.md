# 小企鹅输入法 · 全部界面 UI

- `all-pages-export/`：本轮完整 PNG/SVG、可编辑源快照、handoff、动效规格及独立交互原型 `prototype.html`。
- `全部界面.md`：完整清单与原生代码映射。
- `actual/all-pages/`：QA5 全页面真机截图及历史验证元数据；图片中的记录均为合成数据。正式版受影响页面的验收以根目录交付说明为准。
- `export/` 与原有参考图：上一轮扩展页面基线，保留历史，不作为本轮完整设计的当前版本。

可编辑工作台：http://127.0.0.1:24882/?project=ebe4bbdb50dda9de2c8506e9 。工作台的文字编辑、撤销、保存重开已验证。本次内置“交互预览”入口无响应，改用同版本导出的独立原型验证，没有修改共享工作台代码。

独立原型已实操首页→扩展→关闭/开启 RIME→返回、首页→主题→配置→返回及减少动态效果。修订 10 补充配色模式的打开、手动深色、取消保留、手动日间、返回跟随系统路径。原型导航 220 ms；Android 保留 AndroidX Navigation 默认导航动画，开关使用原生时序，进度展示 150 ms 并遵循禁用动画。网页动画不能代替真机性能证据。

主题页的示意键盘按卡片宽度重新排布，不改变真实输入键盘的高度、留白和用户配置；图片主题编辑仍保留实际键盘裁剪比例。键盘配色提供“跟随系统 / 手动日间 / 手动深色”，沿用原有 Boolean 与主题持久化，不改变旧主题文件格式，也不把时钟当作系统外观。

应用继续使用原有 View/Fragment/Material 技术栈。动态配置页保留引擎实际字段；导入、导出、系统设置、文件选择器及外部网页沿用原有行为。已有主题偏好不被新默认值覆盖，扩展关闭保留用户数据。

字体：Noto Sans SC / Noto Sans CJK SC，SIL OFL 1.1，允许商用。UI 使用正常行度量，键盘文字测量同时尊重 includeFontPadding，避免 Noto CJK 字体全局边界造成留白和数字裁切。
